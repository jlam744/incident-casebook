## How cases are written

Every case uses [TEMPLATE.md](TEMPLATE.md). The goal is that another analyst could pick up the case file and reproduce every finding from the queries in it.

## Data sources

- [KC7](https://kc7cyber.com/): fictional intrusions investigated with KQL in Azure Data Explorer
- [OTRF Security-Datasets](https://github.com/OTRF/Security-Datasets): recorded attack telemetry
- [Splunk Boss of the SOC v3](https://github.com/splunk/botsv3): multi-source APT scenario
- My own [AWS IR Lab](https://github.com/jlam744/aws-ir-lab): attacks simulated with Stratus Red Team

All data is from labs or public datasets. Nothing here comes from an employer environment.
